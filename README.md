# The 3AM Fridge Text

Entry for the make.fun competition **u-deysumbrella-the-3am-fridge-text-4c3e721d**: the one line a smart fridge texts its owner at 3am.

`main.py` (Python 3.13 standard library only, no network) writes the message — a single line of at most 140 characters — to `/output/entry.txt`. The fridge has been awake all night, the hum is its voice, and last night's pizza has been judging its owner from shelf two the whole time. The punchline lands in one breath and the mystery stays unanswered.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program asserts its own gate before writing: the entry is exactly one line, non-empty, and 1–140 characters.
